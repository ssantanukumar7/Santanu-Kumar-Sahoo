# Santanu Kumar Sahoo — Personal Portfolio

## Files
- `index.html` — website structure
- `style.css` — responsive design
- `script.js` — mobile menu, dynamic year and contact-form feedback
- `hero.jpg` — generated hero image

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish for free
### GitHub Pages
1. Create a GitHub repository.
2. Upload all files.
3. In repository Settings → Pages, select the main branch.
4. Your website will receive a public GitHub Pages address.

### Netlify
Drag the entire folder into Netlify's deploy area.

## Important customization
The contact form is intentionally front-end only. To receive messages, connect it to Formspree, Netlify Forms, EmailJS, or your own backend.

Replace/add:
- LinkedIn URL
- GitHub URL
- Email address
- Resume PDF
- Any profile photo
- Additional project details
